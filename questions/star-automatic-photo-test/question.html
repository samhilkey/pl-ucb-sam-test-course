Automatic photo recognition sandbox

Use Recognize a graph photo to review a detected graph before adding it to the editable canvas. Recognition is experimental; the supported sample images use thick strokes, straight-on graph paper, and printed numeric labels. If detection is incomplete, use Correct recognition / Use manual tracing with the same photo. Manual calibration and tracing are optional assistance, not automatic recognition. Separate marks can be added with the native point tool.

Sketch $f(x)=x^2$. This sandbox keeps the native $x^2$ grader: an imported sample can be graded incorrect while faithfully preserving its original marks.
