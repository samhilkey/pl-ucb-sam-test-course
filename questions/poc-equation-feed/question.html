Proof of concept: equation → canvas → grade

Nothing on either canvas below is written into this file. A few lines of Python chose an equation when the page loaded, and the curve was generated from it. Reload the page and you get a different equation and a different curve.

In the real system, that equation comes from fitting a parent function to a photo of a hand-drawn graph. Everything downstream of the fit is what you see here.

1. A correct fit. The question is grading against $f(x) = {{params.target_latex}}$, and the curve seeded onto the canvas was generated from that same equation. Drag the purple control points and submit to see the grading respond.

2. A bad fit. Same target function, but the curve seeded onto this canvas was generated from an equation with the wrong vertical stretch. Submit without touching it: grading should fail, which is the point. A seeded curve is a real submission, not decoration, and a wrong fit does not quietly pass.
